## Documentation Standards

When adding new documentation:

1. **API Changes**: Update the API_DOCUMENTATION.md file
2. **Feature Implementation**: Create detailed implementation guides like WORKER_TARGETS_IMPLEMENTATION.md
3. **Setup Instructions**: Update the main README.md file
4. **Code Examples**: Include practical examples with proper formatting
5. **Version Information**: Keep track of API versions and changes
